# 自制 RPG Maker MV 插件套件 · 使用说明

本套件包含 4 个为 RPG Maker MV 编写的自制插件，围绕「**图片式自定义菜单 + WASD 移动 + 读档状态修复**」这组需求协作工作。

| 插件 | 作用 | 作者 |
|------|------|------|
| **WASDMovement** | 让 WASD（或任意自定义按键）拥有方向键的全部功能 | 清寒不知雨 |
| **PreloadMenuPictures** | 游戏启动时预加载菜单图片，避免首次打开闪烁/卡顿 | 清寒不知雨 |
| **LoadGameFix** | 读档/新游戏/进地图后自动重置菜单状态，避免残留 | 清寒不知雨 |
| **PictureMenuMouse** | 图片式自定义菜单（ESC 开关 + 鼠标点击 + 键盘选择） | 清寒不知雨 |

---

## 一、安装与启用

1. 将 4 个 `.js` 文件复制到项目的 `js/plugins/` 目录。
2. 在 RPG Maker MV 的「插件管理器」中依次勾选启用（名称需与文件名一致）。
3. 加载顺序（推荐，见下方说明）：

   ```
   WASDMovement → PreloadMenuPictures → LoadGameFix → PictureMenuMouse
   ```

> **关于加载顺序**：本套件已做防御性编码（关键参数均有默认值兜底；菜单恢复逻辑放在 `update()` 首帧，不依赖钩子执行顺序），因此插件间相对顺序即使略有调整也不会导致功能失效。但**菜单类图片/资源类插件建议放在最上方、核心逻辑插件放在下方**，便于排查。

---

## 二、各插件详解

### 1. WASDMovement —— WASD 移动

把指定物理按键映射到方向键符号（`up/down/left/right`），从而让移动、菜单、确认等所有依赖方向键的操作都自动支持这些按键。**不影响原版方向键**。

| 参数 | 说明 | 默认 |
|------|------|------|
| Up Key Code | 映射为「上」的按键 KeyCode，可填多个（逗号分隔） | `87`（W） |
| Down Key Code | 映射为「下」 | `83`（S） |
| Left Key Code | 映射为「左」 | `65`（A） |
| Right Key Code | 映射为「右」 | `68`（D） |

- 常用 KeyCode：`W=87 A=65 S=83 D=68`；小键盘方向键 `104/98/100/102` 也可填入。
- 想用 IJKL 移动：`Up=73 Down=74 Left=75 Right=76`。
- **即使 `plugins.js` 未写入参数也能开箱即用**（代码内置了上述默认值兜底）。

---

### 2. PreloadMenuPictures —— 菜单图片预加载

在 `Scene_Boot`（游戏启动）时预加载 `img/pictures` 下的指定图片，保证图片菜单首次出现时即时显示、不闪烁。

| 参数 | 说明 | 默认 |
|------|------|------|
| Picture List | 需预加载的图片文件名（不含扩展名，逗号分隔） | `0,1,2,3,4` |
| Debug Log | 是否在控制台输出预加载信息 | `false` |

- 应与 **PictureMenuMouse** 的「Menu Pictures」保持一致，确保菜单用到的图都被预缓存。

---

### 3. LoadGameFix —— 读档状态修复

读档成功、开始新游戏、进入地图时，自动 **关闭菜单开关**、**擦除指定图片槽位**、**归零指定变量**，让图片菜单从干净状态开始，避免「读档后菜单图片残留/错乱」。

| 参数 | 说明 | 默认 |
|------|------|------|
| Menu Switch ID | 菜单开关 ID（**必须与 PictureMenuMouse 设成同一个**） | `1` |
| Reset Picture IDs | 读档/新游戏后擦除的「显示图片」槽位（逗号分隔） | `0,1,2,3,4` |
| Reset Variable IDs | 读档/新游戏后归零的变量（逗号分隔，常用于菜单选中项） | `1` |
| Debug Log | 是否输出调试信息 | `false` |

- **插件指令**：`ResetMenuState` —— 在事件中手动重置上述菜单状态。

> 注意：本插件会在 `Scene_Map` 每次 `start()` 时关闭菜单开关（用于「进地图即关菜单」）。PictureMenuMouse 已专门处理「从物品/存档/读档子场景返回」的场景，会在返回后自动重新打开菜单，二者配合无需额外配置。

---

### 4. PictureMenuMouse —— 图片式自定义菜单（核心）

通过「禁用原版菜单 + ESC 调出图片」实现自制图片菜单。菜单显示时**玩家无法移动、原版菜单被禁用**。

| 参数 | 说明 | 默认 |
|------|------|------|
| Menu Switch ID | 菜单显示/隐藏开关 ID（**必须与 LoadGameFix 一致**） | `1` |
| Menu Pictures | 菜单图片文件名（不含扩展名，逗号分隔，从上到下对应 0~4 项） | `0,1,2,3,4` |
| Function Areas | 各菜单项**点击区域**：`x,y,宽,高`；多项用 `;` 分隔（与菜单项一一对应） | 见下 |
| Default Picture Index | 打开菜单时默认高亮的图片索引（0-4） | `0` |
| Debug Log | 是否输出调试信息 | `false` |

- **Function Areas 默认值**（5 项）：
  ```
  408,418,200,25; 408,448,200,25; 408,472,200,25; 408,499,200,25; 408,526,200,25
  ```
  即每个区域宽 200、高 25，左边缘 x=408，y 从 418 起每 30 像素一项。需按你菜单图片的实际布局调整。

- **固定五项功能**（顺序与图片/区域一一对应）：
  `退出游戏` / `物品` / `存档` / `读档` / `返回标题`

- **操作方式**：
  - `ESC`：打开 / 关闭菜单
  - `↑` / `↓`：切换选项；`回车` / `空格`：确认
  - 鼠标点击 `Function Areas` 定义的区域：直接选择并确认

- **插件指令**：
  | 指令 | 作用 |
  |------|------|
  | `ShowMenu` | 打开菜单 |
  | `HideMenu` | 关闭菜单 |
  | `SetMenuSelection n` | 设置当前选中项（n 为 0~4） |

## 三、菜单配置要点（必读）

要让图片菜单正常显示并响应点击，需同时满足：

1. **图片就位**：`Menu Pictures` 列出的文件名（如 `0.png`~`4.png`）必须存在于项目的 `img/pictures/` 目录。
2. **开关一致**：`PictureMenuMouse` 与 `LoadGameFix` 的 **Menu Switch ID 必须相同**（默认都是 `1`）。
3. **点击区域匹配**：`Function Areas` 的坐标/尺寸要覆盖你菜单图片上各按钮的实际位置，否则鼠标点击会「点不中」。
4. **预加载同步**：`PreloadMenuPictures` 的 `Picture List` 建议与 `Menu Pictures` 保持一致。

---

## 四、已知注意事项

- **图片必须存在**：若 `Menu Pictures` 指向的图片缺失，菜单会显示空白/报错；请先确认 `img/pictures` 下文件齐全。
- **Debug Log**：排查问题时把相关插件的 `Debug Log` 设为 `true`，可在浏览器 F8 控制台看到 `[WASDMovement]` / `[LoadGameFix]` / `[PictureMenuMouse]` / `[PreloadMenuPictures]` 前缀的日志。
- **子场景返回**：在菜单里选「物品/存档/读档」后按 `ESC` 返回，菜单会自动保持打开并恢复鼠标/键盘控制（无需再按一次 ESC）。
- **本套件针对特定工程做了适配**：该工程引擎对 `Scene_Map` 显示对象创建、插件参数读取做了定制修改，菜单精灵在 `onMapLoaded → createDisplayObjects` 中异步创建，插件已据此处理渲染层级与输入焦点。

## 五、快速自检清单

- [ ] 4 个插件均已启用，且放在其他插件之前/合适位置
- [ ] `Menu Switch ID` 在 LoadGameFix 与 PictureMenuMouse 中一致
- [ ] `img/pictures/` 下存在 Menu Pictures 对应图片
- [ ] `Function Areas` 坐标与菜单图片布局匹配
- [ ] 进游戏后按 `ESC` 能弹出图片菜单；`WASD` 能在地图上移动
- [ ] 菜单中选「物品」→ `ESC` 返回后菜单仍在且可正常操作
